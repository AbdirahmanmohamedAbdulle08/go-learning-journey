# Go Programming Course

A structured learning repository documenting my journey of learning the Go programming language, from Week 1 to Week 8.

This repository contains my daily practice, coding exercises, assignments, projects, and progress throughout the course.

## About This Repository

The main goal of this repository is to develop a strong foundation in Go programming through consistent practice and hands-on projects.

Each week focuses on specific programming concepts, with practical exercises and projects to apply what I have learned.

## Course Structure

The repository is organized into eight weekly sections:

| Week | Description |
| --- | --- |
| Week 1 | Go fundamentals, basic syntax, variables, data types, operators, and CLI Calculator |
| Week 2 | Programming concepts and practical exercises |
| Week 3 | Functions and structured programming |
| Week 4 | Data structures and collections |
| Week 5 | Error handling and file operations |
| Week 6 | Packages, modules, and project organization |
| Week 7 | Advanced Go concepts and practical projects |
| Week 8 | Final projects, revision, and course completion |

*Note: The weekly descriptions are a general learning roadmap and may be updated as the course progresses.*

- Supports basic arithmetic operations.
- Performs input validation.
- Handles invalid input and division by zero.
- Uses Go's standard library for command-line interaction.
